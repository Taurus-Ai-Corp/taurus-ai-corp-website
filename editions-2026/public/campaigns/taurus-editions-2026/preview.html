COMPONENTS

EDITORIAL PRIMITIVES

Components are pages, not widgets. A button is a page reference. A table is an index. A dialog is a footnote. Every primitive inherits the industrial grid and neon platform ink.

Running Head

Fixed top bar with section name and folio number. Fades in on scroll, stamps the page identity.

Folio

Page number block with bottom rule. Industrial mono, stamped uppercase, 160px min-width.

Platform Bar

Neon accent bar (96x5px) with triple-layer glow. Color matches the active volume's ink tint.

Chapter Opener

Full-bleed section with background image, platform tint, folio, and chapter number. Roll motion animates the background.

Marginalia

Side notes in mono, tinted with platform ink. Appears as a footnote on wide screens, inline on mobile.

Index Table

Sortable table with mono headers, hairline rules. Cell backgrounds glow on hover with the platform tint.

Line Rule

Horizontal divider that draws from left to right on scroll. 1px hairline with optional platform-color glow.

Page Break

Full-width rule between sections. Animates from scaleX(0) to scaleX(1) with page-turn easing.

WORKFLOW

DESIGN-TO-CMS PIPELINE

From token spec to deployed page. Each step is a gate with a pass/fail test.

STEP 01
TOKENS
tokens.json (DTCG 2025.10) defines color, type, spacing, motion, and platform ink tints. Source of truth for all platforms.
STEP 02
SCSS
Platform SCSS files import _tokens.scss and emit per-volume CSS custom properties. Each platform overrides only its ink tint.
STEP 03
COMPONENTS
React/Vue components consume CSS custom properties. No hardcoded colors. Every component reads --platform from its section.
STEP 04
CMS SCHEMA
Volume, Chapter, Section, and Content types. Each content entry carries a platform reference that sets the ink tint.
STEP 05
ASSETS
Background images stored per platform. CSS background-image layers with roll + scrollmotion animation. No img tags in the HTML body.
STEP 06
DEPLOY
Static export to Vercel/Cloudflare. Preview gate: preview.html must pass structural verification before production deploy.

CHAPTER 05

REAL BOOK INTEGRATION

The corporate website is a book. Each platform is a volume. Every product launch is a chapter. Every campaign is a folio. The reader scrolls through pages, not screens. Backgrounds roll and shift with scroll motion, creating the physical feeling of turning pages.

The book is not a metaphor. It is the architecture.
Pages are sections. Chapters are products. The spine is the brand.

WHITE PAPER

Each platform publishes technical white papers as book chapters. Readers scroll through multi-page documents with running heads, footnotes, and marginalia. Background images shift per section.
